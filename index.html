💡 怎么用

▸
在微信里打开就能直接用 ✅ 提醒方式是页面内提醒卡片 + 声音，有震动就用震动，没有（比如 iPhone 的微信）就用屏幕边缘闪一下代替（微信不开放系统通知，所有网页都一样）。
小技巧：想让提醒更不容易被系统冻结，点右上角「…」→「在浏览器打开」，或浏览器菜单里「添加到主屏幕」，用起来更像 App。
提醒靠页面本身发出：页面要保持在后台或前台开着。手机锁屏久了系统可能冻结网页，建议到点前把页面调出来看一眼。
· 点「＋ 添加」先选事项性质：
  时间段——有开始和结束，比如「14:00–16:00 实验课」，进行中会绿底高亮；
  截止时间——只有一个截止时刻，比如「周五 23:59 前交报告」，卡片标「截止」，到点提醒、过期变红。
· 时间段里结束早于开始会算成跨天（22:00 → 01:00）；日期下面有「今天/明天/后天/一周后」快捷按钮，下方还会提示「几月几日 周X」；截止类另有一键「今天/明天/3 天后/一周后 23:59」。
· 到点会弹提醒卡片 + 提示音 + 震动，可以直接在卡片上「标记完成」。
· 正在进行的日程会显示绿底「进行中」；当天已过时间但还没勾完成的会变红、继续留在时间轴上，第二天才收进「已结束 / 已逾期」。
· 顶部 短期提醒 是随手记，不用填时间：点「＋ 添加短期提醒」输入后回车；点左侧圆点标为重要；点文字可改。
· 多设备同步：服务器地址和 key 已经内置好了，你只需要在「提醒设置」里定一个同步码（≥6 位），另一台设备打开这个页面填同一个同步码，数据就过来了。改动后约 3 秒上传，切回页面自动拉取；断网也能用，联网后自动补上。
· 当天的日程做完了不会马上消失：勾完成后它继续留在当天的时间轴上（变灰加删除线），第二天才收进下面的「已结束 / 已逾期」。跨天的日程（22:00 → 次日 01:00）会在开始那天和结束那天各显示一次，第二天那张会标「昨天开始」。
· 在电脑上用鼠标：点一下日期/时间框就弹出应用自带的日历和时间列表（电脑和微信里长得一样）；悬停到 ✓ ✎ 🗑 上会显示按钮名称；Esc 关闭弹窗，Ctrl / ⌘ + Enter 直接保存；点弹窗外面的灰色区域也能关。
· 数据默认只存在这台设备的浏览器里（localStorage）；开了同步才会加密上传到你自己的 Supabase 项目。清理微信/浏览器缓存会清掉本机数据（云端还在，填回同步码就能拉回来），重要内容也可以点「复制备份」存一段文字。
